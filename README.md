Fake News Detector

An AI-powered web application that helps detect whether a given news statement is likely to be real or fake.

🌐 Live Demo

https://fakenewsdetector-nine-sepia.vercel.app/

 ✨ Features

- 🔍 Fake news detection
- 🤖 AI/NLP-based analysis
- 🌐 Simple and user-friendly web interface
- ⚡ Quick prediction results
- 📱 Responsive frontend

🛠️ Technologies Used

- Python
- Flask
- Natural Language Processing (NLP)
- HTML
- CSS
- JavaScript

📂 Project Files

- `app.py` – Main Flask application
- `nl_engine.py` – NLP and fake-news detection logic
- `index.html` – Frontend webpage
- `styles.css` – Website styling
- `app.js` – Frontend JavaScript
- `requirements.txt` – Python dependencies
